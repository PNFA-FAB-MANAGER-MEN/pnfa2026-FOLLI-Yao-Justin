## Appris

### Atelier 1 — MicroPython & station météorologique
- **MicroPython** est une version allégée de Python conçue pour tourner directement sur un microcontrôleur (ESP32, etc.).
- Le **DHT22** mesure température et humidité ; l'**écran OLED** permet un affichage des données directement sur le montage, sans ordinateur relié en permanence.

- **Flasher** un microcontrôleur consiste à installer l'interpréteur (ici MicroPython) directement sur la mémoire de l'ESP32 pour qu'il exécute du code Python sans compilation externe.
- Le bon choix du **port série** est indispensable pour que l'IDE communique avec la carte physique.
